# Multiplication Game

This is a simple multiplication game where two players can input numbers, and the game will determine the winner based on the product of the numbers. The player with the higher score wins. The game keeps track of the scores for both players and updates them accordingly.

## How to Play

1. Two cards will be displayed on the screen with a number on each card.
2. Each player will input a number in the provided input fields.
3. After both players have entered their numbers, click the "Submit" button.
4. The game will calculate the product of the numbers and determine the winner.
5. The scores will be updated based on the results of each round.

> Pretty simple, right? Enjoy playing the multiplication game!
